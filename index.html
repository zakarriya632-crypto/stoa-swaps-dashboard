Data sources & methodology

  • Primary — Robinhood Chain public JSON-RPC https://rpc.mainnet.chain.robinhood.com (CORS: access-control-allow-origin: *, verified 2026-11-20). eth_getLogs on StoaRouter 0x2F2804fad735a38015650f32f95Ad5E08D6B3eE5 from deployment block 114,244,443, topic0 0x2bbce25631e8fa58085b7ea5929726c3acdf2df8d6b1f099eb32fb7425a4f6da = Routed(address,address,address,address,address,uint256,uint256,address,address,address) (contracts/src/StoaRouter.sol). Block timestamps via eth_getBlockByNumber. Full queries in README.md.
  • Prices — Stoa quote API GET https://stoadex.com/api/v1/quote?chain=robinhood&…&referrer=0x91be… (CORS: *, verified 2026-11-20). ETH, $STOA and Stoa Exchange token are priced from live quotes; USDG is $1 by definition (6 decimals).
  • Cross-check — Stoa's own stats https://stoadex.com/api/stats (attempted in-browser; it sends no CORS header, so most browsers block it — its status is shown below). Last verified by curl 2026-11-20 14:58 UTC: Robinhood 31 swaps, $634.45 all-time, 1 swap / $4.02 in 24h, first swap 2026-11-14 19:00:34 UTC — exactly matching this dashboard's RPC count.
  • Explorer — Blockscout https://robinhoodchain.blockscout.com. Its API v2 is Cloudflare-challenged from datacenter IPs (verified 2026-11-20), so the dashboard does not depend on it; every transaction links to its Blockscout page for verification.

Honest note: activity is small. 31 swaps since launch (first 2026-11-14), about $634 of volume. Nothing here is inflated or estimated from a sample — the tables list every swap found in the logs.
